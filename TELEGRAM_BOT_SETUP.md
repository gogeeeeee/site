# Підключення замовлень до Telegram

Сайт надсилає замовлення на `/api/orders`. Сервер у `server.py` перевіряє товари та ціни за `json/store_db.json` і відправляє повідомлення адміністратору через Telegram Bot API. Токен бота зберігається лише в змінних середовища сервера.

## Локальний запуск у Windows PowerShell

1. Створіть бота через [@BotFather](https://t.me/BotFather) командою `/newbot` і скопіюйте токен.
2. Відкрийте чат із новим ботом та надішліть `/start`.
3. У PowerShell перейдіть до папки проєкту та задайте налаштування. Введення токена через `Read-Host` не показує його на екрані:

   ```powershell
   $env:TELEGRAM_BOT_TOKEN = Read-Host "Введіть токен бота"
   $updates = Invoke-RestMethod "https://api.telegram.org/bot$env:TELEGRAM_BOT_TOKEN/getUpdates"
   $updates.result | ForEach-Object { $_.message.chat.id }
   $env:TELEGRAM_CHAT_ID = Read-Host "Введіть показаний chat id"
   python server.py
   ```

4. Відкрийте адресу, показану сервером (за замовчуванням `http://127.0.0.1:8000`), додайте товар і оформіть тестове замовлення. Сервер і сайт мають працювати з одного origin, щоб `/api/orders` потрапляв у цей самий сервер.

Якщо `getUpdates` порожній, перевірте, що спершу надіслали боту `/start`. Для групи додайте бота до групи, надішліть повідомлення в групу й використайте її `chat.id` (зазвичай від'ємне число).

## Розгортання

Розгорніть статичні файли та `server.py` на одному хостингу із серверною підтримкою Python і HTTPS. У налаштуваннях хостингу додайте секрети `TELEGRAM_BOT_TOKEN` та `TELEGRAM_CHAT_ID`, а потім запустіть `python server.py` або налаштуйте команду запуску, яку вимагає платформа. Для зовнішнього доступу сервер має слухати адресу, призначену хостингом; платформні змінні `HOST` і `PORT` підтримуються. Не додавайте токен до HTML/JavaScript, Git або публічних логів. Якщо API розміщене на іншому домені, потрібно окремо налаштувати адресу API та CORS.

Поточний шаблон приймає оплату при отриманні або банківським переказом після підтвердження менеджером. Онлайн-оплата карткою не підключена. Telegram-повідомлення містить контактні та адресні дані покупця — використовуйте лише власний довірений чат адміністраторів.
